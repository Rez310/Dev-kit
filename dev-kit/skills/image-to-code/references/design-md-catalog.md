# Catalogue DESIGN.md (VoltAgent/awesome-design-md)

Dépôt : https://github.com/VoltAgent/awesome-design-md (MIT). Chaque entrée contient un `DESIGN.md` (le design system, ce que lisent les agents) et des pages `preview.html` / `preview-dark.html` (catalogue visuel).

URL d'une marque : `https://getdesign.md/<slug>/design-md`

Les fichiers décrivent des valeurs CSS publiques observées sur les sites ; ils servent d'inspiration. Ne pas reproduire les logos, noms ou visuels de la marque. Le catalogue évolue : si la marque cherchée n'est pas listée ici, consulter le dépôt.

Format : `slug` — ambiance en quelques mots.
